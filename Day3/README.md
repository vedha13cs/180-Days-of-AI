---

🧠 What I Learned

🔹 Array Indexing

Accessing individual elements from an array.

numbers[0]
numbers[-1]

🔹 Array Slicing

Selecting a specific portion of an array.

numbers[1:4]

🔹 Array Operations

I practiced mathematical operations directly on arrays:

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division

🔹 Reshaping

I learned how to change the structure of an array without changing its data.

array.reshape()

🔹 Boolean Filtering

I learned how to select values based on conditions.

numbers[numbers > 50]

This concept is especially useful when working with real-world datasets.
