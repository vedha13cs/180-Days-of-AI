🌱 Today's Focus

On Day 4, I learned how to work with Pandas DataFrames.

Today, I learned an important step that comes before Machine Learning:

🧹 DATA CLEANING

A Machine Learning model is only as useful as the data we give it.

Real-world datasets can contain:

❌ Missing values
❌ Duplicate records
❌ Incorrect data
❌ Unnecessary columns
❌ Inconsistent information

So before building a model, we need to prepare the data.

---

🧠 What I Learned

🔍 Selecting Data

I practiced selecting:

- Individual columns
- Multiple columns
- Specific rows
- Rows based on conditions

🕳️ Missing Values

I learned to identify missing values using:

isnull()

and handle them using:

fillna()
dropna()

♻️ Duplicate Data

I learned how to identify and remove duplicate records using:

duplicated()
drop_duplicates()

🧹 Cleaning Data

I also practiced:

- Renaming columns
- Replacing incorrect values
- Checking data types
- Removing unnecessary data
