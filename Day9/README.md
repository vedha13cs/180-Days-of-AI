🌱 Today's Focus

Today I learned about Exploratory Data Analysis (EDA).

EDA is the process of exploring a dataset to understand:

«What does the data look like? What patterns are hiding inside it?»

It brings together many of the concepts I've learned during the first 8 days.

🧠 What I Learned

📋 01 — Understand the Dataset

I practiced checking:

- Number of rows
- Number of columns
- Column names
- Data types
- Basic statistics

🧹 02 — Check Data Quality

I learned to look for:

- Missing values
- Duplicate records
- Unexpected values

📊 03 — Analyze the Data

I explored:

- Mean
- Median
- Minimum
- Maximum
- Correlations
- Distribution of values

- Comparisons
- Trends
- Relationships
- Outliers
