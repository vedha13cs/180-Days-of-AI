🧠 What I Learned

🎲 What is Probability?

Probability represents how likely an event is to happen.

Its value ranges from:

0 ─────────────── 1

Impossible       Certain

Or equivalently:

0% ───────────── 100%

---

📌 Basic Formula

Probability of an Event

        Favorable Outcomes
P(E) = ────────────────────
         Total Outcomes

---

🪙 Example — Coin Toss

A fair coin has two possible outcomes:

Heads
Tails

Therefore:

P(Heads) = 1 / 2 = 0.5 = 50%

---

🎲 Example — Dice

A standard dice has six possible outcomes:

1  2  3  4  5  6

Probability of getting a 6:

P(6) = 1 / 6

---

🤖 Why Probability Matters in AI

Probability helps us understand:

- 🔮 Predictions
- 📊 Uncertainty
- 🧠 Classification
- 🎯 Decision making
- 📈 Risk estimation
- 🤖 Machine Learning models

For example, a model might predict:

Cat → 90%
Dog → 10%

The model is expressing how confident it is in its prediction.
