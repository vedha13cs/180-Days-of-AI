Today I explored:

- 📈 Line charts
- 📊 Bar charts
- 🥧 Pie charts
- 🔵 Scatter plots
- 🏷️ Titles and labels
- 📐 Figure size
- 📌 Grid and legends

---

🔍 Why Visualization Matters in AI

Before training a Machine Learning model, we often need to understand our data.

Visualization can help identify:

📈 Trends
📊 Comparisons
🔗 Relationships
⚠️ Outliers
📉 Patterns

This makes Exploratory Data Analysis (EDA) an important part of the AI/ML workflow.
