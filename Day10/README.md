🧠 What I Learned

🔹 What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence where algorithms learn from data to identify patterns and make predictions.

A simple idea:

📊 DATA
   ↓
🤖 ML ALGORITHM
   ↓
🧠 LEARN PATTERNS
   ↓
🎯 PREDICTION

---

🧩 Types of Machine Learning

01 — Supervised Learning 🎯

The model learns from labelled data.

Examples:

- Predicting house prices
- Predicting exam marks
- Email spam detection

Input + Known Output
        ↓
       Model
        ↓
   New Prediction

---

02 — Unsupervised Learning 🔎

The model works with data without predefined labels and tries to discover patterns or groups.

Example:

«Customer segmentation»

Data
 ↓
Algorithm
 ↓
Hidden Patterns / Groups

---

03 — Reinforcement Learning 🎮

An agent learns by interacting with an environment and receiving rewards or penalties.

Examples:

- Game-playing AI
- Robotics
- Decision-making systems

Term| Meaning
