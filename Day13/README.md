🧠 What is Multiple Linear Regression?

Multiple Linear Regression predicts a continuous target using two or more independent variables.

The general equation is:

y = b₀ + b₁x₁ + b₂x₂ + b₃x₃ + ... + bₙxₙ

Where:

- "y" → Predicted target
- "b₀" → Intercept
- "x₁, x₂, ..." → Features
- "b₁, b₂, ..." → Feature coefficients

🔍 Important Concept

In Machine Learning:

X → Features
y → Target

For example:

X = [
    [1000, 2, 1],
    [1500, 3, 2],
    [2000, 4, 3]

Here, each row represents one house and each column represents a feature.
