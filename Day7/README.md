🧠 What I Learned

📊 Mean

The average value of a dataset.

Mean = Sum of values / Number of values

📍 Median

The middle value when the data is arranged in order.

🔁 Mode

The value that appears most frequently.

📏 Range

The difference between the maximum and minimum values.

Range = Maximum − Minimum

📈 Variance

Measures how far values are spread from the mean.

📐 Standard Deviation

Measures the amount of variation or spread in a dataset.

A smaller standard deviation generally means the values are closer to the mean.
